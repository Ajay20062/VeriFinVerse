FIELD NOTES / 03

How to read a signal

A

Confidence

When returned, confidence is the model's probability for its classification. It may be unavailable.

B

Combined result

The API combines model labels by majority vote. A tie is returned as UNCERTAIN.

C

Model availability

Only models configured with local artifacts can analyze text. An unavailable model is not a negative result.
